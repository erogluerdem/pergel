📖 Giriş: PERGEL HTML Sistemi

PERGEL, modern Laravel 11 tabanlı bir kurum yönetim sistemdir. HTML yapısı, Bootstrap 5 ve özel CSS ile oluşturulmuş, ölçeklenebilir ve sürdürülebilir bir tasarıma sahiptir.

Temel Özellikler

  • Bootstrap 5: Responsive ve mobil-first tasarım
  • Blade Şablonları: Laravel'in güçlü template engine'i
  • Font Awesome: 6000+ ikon kütüphanesi
  • Özel CSS: Santiye ve kurumsal tema desteği
  • JavaScript: Etkileşimli bileşenler ve validasyon
ℹ️ Bilgi: Bu rehberi okurken, projenizin views/ klasöründeki dosyaları referans alarak takip etmeniz önerilir.

🏗️ Master Layout Yapısı

Tüm sayfaların temel yapısını sağlayan ana şablon dosyası: layouts/master.blade.php

Temel Sayfa Şablonu

<!DOCTYPE html> <html lang="en"> <head> <meta charset="utf-8" /> <title>@yield('title') | Pergel</title> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!-- Favicon --> <link rel="shortcut icon" href="{{ URL::asset('build/images/favicon.ico') }}"> <!-- Başlık CSS Dosyaları --> @include('layouts.head-css') <!-- Sayfa Spesifik Stiller --> @stack('styles') </head> <body> <div id="layout-wrapper"> <!-- Üst Bar --> @include('layouts.topbar') <!-- Yan Menu --> @include('layouts.sidebar') <!-- Ana İçerik --> <div class="main-content"> <div class="page-content"> <div class="container-fluid"> <!-- Sayfa Başlığı --> <div class="page-title-box"> <h4>@yield('title')</h4> </div> <!-- Ana Sayfa İçeriği --> @yield('content') </div> </div> </div> <!-- Alt Bilgi --> @include('layouts.footer') </div> <!-- Vendor Scripts --> @include('layouts.vendor-scripts') @stack('scripts') </body> </html>
⚠️ Dikkat: Yeni sayfa oluştururken mutlaka master.blade.php dosyasını extend edin. Sayfanız bootstrap yapısını otomatik olarak kalıtım alacaktır.

Master Yapısının Bileşenleri

Bileşen Dosya Açıklama
Topbar layouts/topbar.blade.php Sayfa üst kısmı (kullanıcı menüsü, bildirimler)
Sidebar layouts/sidebar.blade.php Sol yan menü (modüllere erişim)
Head CSS layouts/head-css.blade.php CSS dosyaları (Bootstrap, Font Awesome vb.)
Vendor Scripts layouts/vendor-scripts.blade.php JavaScript kütüphaneleri
Footer layouts/footer.blade.php Sayfa alt kısmı (telif, bağlantılar)

📐 Layout Sistemi: Bootstrap 5 Grid

PERGEL, Bootstrap 5'in güçlü grid sistemini kullanarak responsive tasarımlar sağlar.

Grid Yapısı Temel Kurallar

<div class="container-fluid"> <!-- Satır --> <div class="row"> <!-- Sütun: 12 birimlik sistem --> <div class="col-md-6"> Yarısı </div> <div class="col-md-6"> Diğer Yarısı </div> </div> <!-- Üç Sütunlu Layout --> <div class="row"> <div class="col-md-4"> 1/3 </div> <div class="col-md-4"> 1/3 </div> <div class="col-md-4"> 1/3 </div> </div> </div>

Responsive Breakpoints

Breakpoint Sınıf Öneki Genişlik Kullanım
Extra Small .col- < 576px Mobil Telefonlar
Small .col-sm- ≥ 576px Yatay Telefonlar
Medium .col-md- ≥ 768px Tabletler
Large .col-lg- ≥ 992px Masaüstü
Extra Large .col-xl- ≥ 1200px Geniş Ekran

🧩 Bootstrap 5 Bileşenleri

Sistemde yaygın olarak kullanılan Bootstrap 5 bileşenleri ve bunların PERGEL'de kullanım şekilleri:

1. Kartlar (Cards)

<div class="card"> <img src="..." class="card-img-top" alt="..."> <div class="card-body"> <h5 class="card-title">Kart Başlığı</h5> <p class="card-text">Kart içeriği...</p> <a href="#" class="btn btn-primary">Buton</a> </div> <div class="card-footer"> Kart Altı Bilgisi </div> </div>

2. Butonlar (Buttons)

<!-- Temel Butonlar --> <button class="btn btn-primary">Birincil</button> <button class="btn btn-secondary">İkincil</button> <button class="btn btn-success">Başarı</button> <button class="btn btn-danger">Tehlike</button> <button class="btn btn-warning">Uyarı</button> <button class="btn btn-info">Bilgi</button> <!-- Buton Boyutları --> <button class="btn btn-primary btn-sm">Küçük</button> <button class="btn btn-primary">Normal</button> <button class="btn btn-primary btn-lg">Büyük</button> <!-- Buton Varyasyonları --> <button class="btn btn-primary">Dolu</button> <button class="btn btn-outline-primary">Çerçeveli</button> <button class="btn btn-primary disabled">Devre Dışı</button>

3. Uyarı Kutuları (Alerts)

<div class="alert alert-primary"> <i class="fas fa-info-circle"></i> Bilgi mesajı </div> <div class="alert alert-success"> <i class="fas fa-check-circle"></i> Başarı mesajı </div> <div class="alert alert-warning"> <i class="fas fa-exclamation-triangle"></i> Uyarı mesajı </div> <div class="alert alert-danger"> <i class="fas fa-times-circle"></i> Hata mesajı </div>

4. Tablolar (Tables)

<table class="table table-striped table-hover"> <thead class="table-dark"> <tr> <th>Sütun 1</th> <th>Sütun 2</th> <th>Sütun 3</th> </tr> </thead> <tbody> <tr> <td>Veri 1</td> <td>Veri 2</td> <td>Veri 3</td> </tr> </tbody> </table>

5. Modal Dialog'lar

<!-- Modal Tetikleyici Buton --> <button type="button" class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#modalExample"> Modal Aç </button> <!-- Modal --> <div class="modal fade" id="modalExample" tabindex="-1"> <div class="modal-dialog"> <div class="modal-content"> <div class="modal-header"> <h5 class="modal-title">Modal Başlık</h5> <button type="button" class="btn-close" data-bs-dismiss="modal"></button> </div> <div class="modal-body"> Modal içeriği... </div> <div class="modal-footer"> <button type="button" class="btn btn-secondary" data-bs-dismiss="modal">Kapat</button> <button type="button" class="btn btn-primary">Kaydet</button> </div> </div> </div> </div>

6. Form Elemanları

<div class="mb-3"> <label for="inputName" class="form-label">Ad</label> <input type="text" class="form-control" id="inputName" placeholder="Adınızı girin"> </div> <div class="mb-3"> <label for="selectOption" class="form-label">Seçim</label> <select class="form-select" id="selectOption"> <option value="1">Seçenek 1</option> <option value="2">Seçenek 2</option> </select> </div> <div class="mb-3"> <label for="textareaNote" class="form-label">Not</label> <textarea class="form-control" id="textareaNote" rows="3"></textarea> </div> <div class="form-check"> <input class="form-check-input" type="checkbox" id="checkboxTerms"> <label class="form-check-label" for="checkboxTerms"> Şartları Kabul Ediyorum </label> </div>

🔥 Blade Şablonları ve Laravel Entegrasyonu

PERGEL, Laravel'in Blade template engine'ini kullanarak dinamik ve reüsable içerik sağlar.

Blade Temel Direktifleri

📌 Master Extend Etme
@extends('layouts.master') @section('title', 'Projeler') @section('topbar-title', 'Yönetim') @section('content') <div class="row"> <div class="col-12"> <h4>Proje Listesi</h4> </div> </div> @endsection @push('scripts') <script> console.log('Bu sayfa özel scripti'); </script> @endpush
🔄 Döngüler ve Şartlar
@if($projects->count() > 0) <table class="table"> <tbody> @foreach($projects as $project) <tr> <td>{{ $project->name }}</td> <td> @if($project->status == 'active') <span class="badge bg-success">Aktif</span> @elseif($project->status == 'paused') <span class="badge bg-warning">Duraklatılmış</span> @else <span class="badge bg-secondary">Tamamlandı</span> @endif </td> </tr> @endforeach </tbody> </table> @else <div class="alert alert-info"> Henüz proje kayıtlı değil. </div> @endif
📦 Component Kullanma
<!-- Basit Component --> <x-component-name /> <!-- Parametreli Component --> <x-alert-box type="success" message="İşlem başarılı!" /> <!-- Slot ile Component --> <x-card> <x-slot name="title">Kart Başlığı</x-slot> Kart içeriği burada </x-card>

PERGEL'de Sık Kullanılan Blade Direktifleri

Direktif Kullanım Örnek
@extends() Master layout'u miras alma @extends('layouts.master')
@section() Section tanımlama @section('content')
@include() Başka view dosyası dahil etme @include('partials.header')
@foreach() Dizi üzerinde döngü @foreach($items as $item)
@if() Şarta bağlı gösterim @if($user->isAdmin())
{{ }} Değişken çıktısı {{ $user->name }}
@auth() Kullanıcı giriş yapmış mı? @auth ... @endauth
💡 Profesyonel İpucu: Blade şablonlarında güvenlik önemlidir. Kullanıcı inputi gösterirken {{ }} kullanın (XSS koruması), ham HTML çıktısı için {!! !!} kullanın.
