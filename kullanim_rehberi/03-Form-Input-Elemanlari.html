📋 Temel Form Yapısı

Formlar, kullanıcıdan veri toplamak için kullanılan en önemli HTML öğeleridir. PERGEL'de Bootstrap 5'in form bileşenleri kullanılmaktadır.

Basit Form Örneği

<form method="POST" action="/kaydet"> @csrf <div class="mb-3"> <label for="ad" class="form-label">Adınız</label> <input type="text" class="form-control" id="ad" name="ad" placeholder="Adınızı girin" required> </div> <div class="mb-3"> <label for="email" class="form-label">E-Posta</label> <input type="email" class="form-control" id="email" name="email" placeholder="email@örnek.com" required> </div> <button type="submit" class="btn btn-primary">Gönder</button> <button type="reset" class="btn btn-secondary">Temizle</button> </form>

Form Elemanları Temel Sınıfları

Sınıf Kullanım Açıklama
.form-label Etiket Form etiketleri (label)
.form-control Input/Textarea Text inputları ve textarea alanları
.form-select Select Açılır menüler
.form-check Checkbox/Radio Onay kutuları ve radyo düğmeleri
.form-text Yardımcı Metin Form alanlarının altında açıklama
.mb-3 Form Grubu Aralığı Form elemanları arasında boşluk
ℹ️ Önemli: Laravel formlarında güvenlik için @csrf direktifi mutlaka eklenmelidir.

⌨️ Input Türleri ve Kullanımı

1. Metin Input'ları

📝 Metin Alanları
<!-- Basit Metin Input --> <input type="text" class="form-control" placeholder="Metin girin"> <!-- E-Posta Input --> <input type="email" class="form-control" placeholder="email@örnek.com"> <!-- Şifre Input --> <input type="password" class="form-control" placeholder="Şifre girin"> <!-- Telefon Input --> <input type="tel" class="form-control" placeholder="+90 (5XX) XXX XX XX"> <!-- URL Input --> <input type="url" class="form-control" placeholder="https://örnek.com"> <!-- Textarea (Çok Satırlı) --> <textarea class="form-control" rows="4" placeholder="Açıklama yazın"></textarea>

2. Sayısal ve Tarih Input'ları

🔢 Sayısal Alanlar
<!-- Sayı Input --> <input type="number" class="form-control" placeholder="Sayı girin" min="0" max="100" step="1"> <!-- Ondalık Sayı --> <input type="number" class="form-control" step="0.01" placeholder="0.00"> <!-- Para Input --> <div class="input-group"> <span class="input-group-text">₺</span> <input type="number" class="form-control" placeholder="0,00" step="0.01"> </div> <!-- Tarih Input --> <input type="date" class="form-control"> <!-- Saat Input --> <input type="time" class="form-control"> <!-- Tarih-Saat Input --> <input type="datetime-local" class="form-control"> <!-- Ay Input --> <input type="month" class="form-control"> <!-- Haftalar Input --> <input type="week" class="form-control">

3. Select (Açılır Menüler)

📌 Seçim Menüleri
<!-- Basit Select --> <select class="form-select"> <option selected>Seçim Yapınız...</option> <option value="1">Seçenek 1</option> <option value="2">Seçenek 2</option> <option value="3">Seçenek 3</option> </select> <!-- Gruplanmış Select --> <select class="form-select"> <optgroup label="Grup A"> <option value="a1">A Seçenekleri 1</option> <option value="a2">A Seçenekleri 2</option> </optgroup> <optgroup label="Grup B"> <option value="b1">B Seçenekleri 1</option> <option value="b2">B Seçenekleri 2</option> </optgroup> </select> <!-- Çoklu Seçim --> <select class="form-select" multiple> <option value="1">Seçenek 1</option> <option value="2">Seçenek 2</option> <option value="3">Seçenek 3</option> </select> <!-- Select2 (PERGEL'de Mevcut) --> <select class="form-select form-select-sm select2"> <option value="">Seçim Yapınız...</option> <option value="1">Seçenek 1</option> <option value="2">Seçenek 2</option> </select>

4. Checkbox ve Radio

☑️ Onay Kutuları ve Radyo Düğmeleri
<!-- Checkbox --> <div class="form-check"> <input class="form-check-input" type="checkbox" id="checkbox1" name="secenek1"> <label class="form-check-label" for="checkbox1"> Seçenek 1 </label> </div> <div class="form-check"> <input class="form-check-input" type="checkbox" id="checkbox2" name="secenek2"> <label class="form-check-label" for="checkbox2"> Seçenek 2 </label> </div> <!-- Radio Düğmeleri --> <div class="form-check"> <input class="form-check-input" type="radio" name="durum" id="radio1" value="aktif"> <label class="form-check-label" for="radio1"> Aktif </label> </div> <div class="form-check"> <input class="form-check-input" type="radio" name="durum" id="radio2" value="pasif"> <label class="form-check-label" for="radio2"> Pasif </label> </div> <!-- Switches (Toggle) --> <div class="form-check form-switch"> <input class="form-check-input" type="checkbox" id="switch1" role="switch"> <label class="form-check-label" for="switch1"> Bildirimleri Aç/Kapat </label> </div>

✅ Form Validasyonu

HTML5 Validasyonu

<form> <!-- Zorunlu Alan --> <input type="text" class="form-control" required> <!-- Min/Max Uzunluk --> <input type="text" class="form-control" minlength="3" maxlength="50"> <!-- Min/Max Değer --> <input type="number" class="form-control" min="0" max="100"> <!-- Pattern (Regex) --> <input type="text" class="form-control" pattern="[A-Za-z]+" title="Sadece harfler girebilirsiniz"> <!-- E-Posta Validasyonu --> <input type="email" class="form-control" required> <!-- Tarih Validasyonu --> <input type="date" class="form-control" required> </form>

Bootstrap Validasyon Stilleri

<!-- Başarılı Validasyon --> <input type="text" class="form-control is-valid"> <div class="valid-feedback"> Harika! Bu değer doğru. </div> <!-- Başarısız Validasyon --> <input type="text" class="form-control is-invalid"> <div class="invalid-feedback"> Lütfen geçerli bir değer girin. </div>
✓ Başarılı
Bu alan zorunludur.

Laravel Validasyonu

@if ($errors->any()) <div class="alert alert-danger"> <ul> @foreach ($errors->all() as $error) <li>{{ $error }}</li> @endforeach </ul> </div> @endif <!-- Alan Bazında Hata --> <input type="email" class="form-control @error('email') is-invalid @enderror"> @error('email') <div class="invalid-feedback"> {{ $message }} </div> @enderror

🚀 İleri Form Bileşenleri

Input Grupları

<!-- Para Input Grubu --> <div class="input-group mb-3"> <span class="input-group-text">₺</span> <input type="number" class="form-control"> <span class="input-group-text">.00</span> </div> <!-- Butonlu Input Grubu --> <div class="input-group mb-3"> <input type="text" class="form-control" placeholder="Ara..."> <button class="btn btn-primary" type="button"> <i class="fas fa-search"></i> </button> </div> <!-- Checkbox ile Input Grubu --> <div class="input-group mb-3"> <div class="input-group-text"> <input class="form-check-input" type="checkbox"> </div> <input type="text" class="form-control"> </div> <!-- Dropdown ile Input Grubu --> <div class="input-group mb-3"> <label class="input-group-text">Ülke</label> <select class="form-select"> <option>Seçiniz...</option> <option value="TR">Türkiye</option> <option value="US">ABD</option> </select> </div>

Floating Labels (Yüzen Etiketler)

<div class="form-floating mb-3"> <input type="email" class="form-control" id="floatingEmail" placeholder="name@example.com"> <label for="floatingEmail">E-Posta Adresi</label> </div> <div class="form-floating mb-3"> <textarea class="form-control" id="floatingTextarea" placeholder="Açıklama yazın"></textarea> <label for="floatingTextarea">Açıklama</label> </div> <div class="form-floating"> <select class="form-select" id="floatingSelect"> <option>Seçim yapınız...</option> <option value="1">Seçenek 1</option> </select> <label for="floatingSelect">Seçim</label> </div>

Form Layout Seçenekleri

<!-- Dikey Layout (Varsayılan) --> <form> <div class="mb-3"> <label for="ad" class="form-label">Ad</label> <input type="text" class="form-control" id="ad"> </div> <div class="mb-3"> <label for="soyad" class="form-label">Soyadı</label> <input type="text" class="form-control" id="soyad"> </div> </form> <!-- Yatay Layout --> <form> <div class="row mb-3"> <label for="ad" class="col-sm-2 col-form-label">Ad</label> <div class="col-sm-10"> <input type="text" class="form-control" id="ad"> </div> </div> <div class="row mb-3"> <label for="soyad" class="col-sm-2 col-form-label">Soyadı</label> <div class="col-sm-10"> <input type="text" class="form-control" id="soyad"> </div> </div> </form> <!-- İnline Layout (Tek Satıra) --> <form class="row gy-2 gx-3"> <div class="col-auto"> <input type="text" class="form-control" placeholder="Ad"> </div> <div class="col-auto"> <input type="text" class="form-control" placeholder="Soyadı"> </div> <div class="col-auto"> <button type="submit" class="btn btn-primary">Gönder</button> </div> </form>
✅ En İyi Pratikler:
  • Her input'a benzersiz ID verin
  • Label'leri her zaman input ile ilişkilendirin (for attribute)
  • Zorunlu alanları işaretleyin (*)
  • Validasyon hataları açık ve net olsun
  • Form gönderdikten sonra başarı mesajı gösterin
