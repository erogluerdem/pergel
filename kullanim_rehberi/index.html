⚡ Hızlı Başlangıç

PERGEL'de yeni sayfa oluştururken bu adımları izleyin:

  1. Master Layout'u Extend Edin: @extends('layouts.master')
  2. Başlık Tanımlayın: @section('title', 'Sayfa Başlığı')
  3. İçerik Ekleyin: @section('content') ... @endsection
  4. CSS Ekleyin: @push('styles') <style> ... </style> @endpush
  5. JavaScript Ekleyin: @push('scripts') <script> ... </script> @endpush

📚 Terimler Sözlüğü

Terim Açıklama
Blade Laravel'in template engine'i. {{ }} ile değişken çıktısı, @if ile şart, @foreach ile döngü yapılır.
Bootstrap Popüler CSS framework'ü. Responsive tasarım, grid sistemi, bileşenler ve utilities sağlar.
Grid Sistemi Bootstrap'in 12 sütunlu layout sistemi. Responsive tasarım için .row ve .col-* kullanılır.
Utilities Bootstrap'in hızlı stilendirme sınıfları. m-3 (margin), p-2 (padding), d-flex (display) vb.
Responsive Tasarımın tüm ekran boyutlarında uygun görünmesi. Breakpoints kullanılarak sağlanır.
CSRF Token Laravel'in güvenlik özelliği. Form'larda @csrf eklenir.
Validasyon Form verilerinin kontrol edilmesi. HTML5 ve Laravel validasyonu kombinlenebilir.
Font Awesome 6000+ profesyonel ikon kütüphanesi. <i class="fas fa-..."> ile kullanılır.
