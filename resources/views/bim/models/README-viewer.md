Viewer Kullanım Rehberi

- Seçim: Model üzerinde tek tıklama ile bir element seçin. Sağ panelde seçili elementin özellikleri (properties) gösterilecektir.
- İzole Etme: Seçili elemanı izole etmek için "Isolate selection" butonuna tıklayın.
- Ölçüm: "Measure" butonunu aktive edin, model üzerinde double-click ile iki nokta seçin; mesafe ölçüsü görüntülenecektir.
- Model Ağacı: Sol alt panelde modelin spatial yapısı listelenir; bir satıra tıklayınca o eleman highlight olur ve properties panel güncellenir.

Notlar:
- Ölçüm ve izolasyon demo amaçlıdır; gerçekte daha hassas geometri bilgisi için server-side parsing (ifcopenshell gibi) ve geometri verisi gerekebilir.
- Eğer `web-ifc-viewer` sürümünüz farklıysa import yolu ve API küçük farklılıklar gösterebilir.
