## 🎓 TEMEL KAVRAMLAR

### **Proje (Project)**
Tek bir inşaat işi veya tesinin tamamıdır. 
- **Örnek:** "Yüksek Katlı Konut Kompleksi - İstanbul"
- **Özellikleri:** Bütçe, Tarihler, Lokasyon, Takım, Durumu

### **Görev (Task)**
Bir projenin alt bileşenleridir.
- **Örnek:** "Temeller Kazı Işı", "Depo Yönetimi", "İnsan Kaynakları"
- **Özellikleri:** Atanan Kişi, Başlangıç/Bitiş Tarihleri, Durumu

### **Kilometre Taşı (Milestone)**
Projedeki önemli dönüm noktalarıdır.
- **Örnek:** "Zemin Katı Tamamlandı", "İş Emri Alındı"
- **Özellikleri:** Tarih, İlerleme, Kritiklik

### **Bütçe (Budget)**
Projenin mali kaynağıdır.
- **Örnek:** "₺52.5 Milyon"
- **Özellikleri:** Toplam, Harcanan, Kalan, Yüzde

### **Fatura (Invoice)**
Müşteriden veya Tedarikçiye olan ödemedir.
- **Örnek:** "Elektrik Tedarikçisine Ödeme: ₺150K"
- **Özellikleri:** Tutar, Tarih, Durum, Ödeme

### **Risk (Risk)**
Projeyi etkileyebilecek olası olumsuzluktur.
- **Örnek:** "Döviz Dalgalanması", "Gecikmiş Ödeme"
- **Özellikleri:** Tür, Etki, Olasılık, Puanlama

## 🆘 SORUN GIDERME (BAŞLANGIÇ)

### **Giriş Yapamıyorum**
```
1. E-posta adresinin doğru olduğundan emin olun
2. CAPS LOCK'un kapalı olduğundan emin olun
3. "Şifremi Unuttum" bağlantısına tıklayın
4. E-postanıza gelen linke tıklayın
5. Yeni şifre belirleyin
```

### **Sayfa Yüklenmiyorsa**
```
1. Sayfayı yenileyin (F5)
2. Tarayıcı cache'ini temizleyin (Ctrl+Shift+Delete)
3. JavaScript'i etkin olduğundan emin olun
4. Farklı bir tarayıcı deneyin
5. İnternet bağlantınızı kontrol edin
```

### **Menü Görünmüyorsa**
```
1. Sayfayı tamamen yenileyin (Ctrl+F5)
2. Oturum kapatıp yeniden açın
3. Tarayıcı cache'ini temizleyin
4. Başka bir cihazdan deneyin
```
